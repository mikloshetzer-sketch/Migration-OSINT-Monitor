# Migration OSINT Monitor

## Overview

Migration OSINT Monitor is an open-source intelligence (OSINT) platform designed to collect, classify and analyze publicly available migration-related information from multiple online sources.

The system is being developed to support long-term monitoring of migration activity, identify emerging trends, detect potential migration signals and maintain a searchable historical database.

## Planned Data Sources

- X (Twitter)
- Reddit
- Mastodon

## Main Features

- Collection of public posts
- Historical database
- Keyword-based filtering
- Location extraction
- Time extraction
- Signal classification
- Trend analysis
- CSV export
